Как это работает

Документ разбивается на абзацы и предложения. Доступны четыре независимые методики ранжирования предложений:

  • TF-IDF + позиция — метод из методички лабораторной работы: вес термина считается по модифицированной формуле TF·IDF, вес предложения — произведение веса содержащихся терминов и функций положения в документе/абзаце.
  • TextRank — предложения образуют граф схожести (по пересечению слов), важность каждого считается степенным методом, аналогично PageRank.
  • Luhn — классический метод: ищутся самые частые содержательные слова документа, вес предложения — по плотности их скопления.
  • Ансамбль — оценки всех трёх методов нормируются и усредняются.
w(t,D) = 0.5 · (1 + tf(t,D)/tf_max(D)) · log(|DB| / df(t))
Posd(Sᵢ) = 1 − BD(Sᵢ)/|D|      Posp(Sᵢ) = 1 − BP(Sᵢ)/|P|
Score(Sᵢ) = Σ tf(t,Sᵢ)·w(t,D)
Weight(Sᵢ) = Posd(Sᵢ) · Posp(Sᵢ) · Score(Sᵢ)   (переключаются слева, в «Дополнительных параметрах»)

MMR и вводные конструкции

MMR (Maximal Marginal Relevance) — вместо чистого топ-N по весу на каждом шаге выбирается предложение с наибольшей разницей между собственным весом и схожестью с уже отобранными; это снижает дублирование близких по смыслу предложений в реферате.

Упрощение вводных конструкций — реализация пункта методички об «удалении вводных конструкций»: у отобранных предложений отсекаются начальные обороты вроде «Таким образом,», «Кроме того,», «However,» и т.п.

IDF: одиночный документ vs коллекция

Определяется автоматически по числу загруженных документов. Один документ — df(t) считается по его абзацам (каждый абзац — псевдо-документ). Два и более — df(t) считается по-настоящему междокументно, |DB| = число документов.

Ключевые слова: TF-IDF vs RAKE

TF-IDF — термины с наибольшим w(t,D), словосочетания группируются вокруг них по вхождению (иерархия). RAKE (Rapid Automatic Keyword Extraction) — кандидатные словосочетания составляются из максимальных последовательностей не-стоп-слов; вес слова — степень совместной встречаемости, делённая на частоту; вес словосочетания — сумма весов слов. Даёт готовые словосочетания без иерархии.

Автоопределение языка и области

Язык — по соотношению кириллицы/латиницы. Предметная область (медицина / искусствоведческая критика — по варианту 10) — по совпадению токенов документа со словарями терминов каждой области.

Информативность реферата

Косинусная схожесть между вектором самых частых содержательных слов документа и тем же вектором, посчитанным только по предложениям реферата — показывает, насколько реферат покрывает основные, часто обсуждаемые темы документа.

Требования варианта 10

RU/EN, метод Sentence extraction, предметные области — научные статьи по медицине и критика произведений изобразительного искусства. Реферат — из двух разделов: классического (набор предложений) и в виде ключевых слов.
